Научи компьютер слышать

Соберём маленький датасет: по 5–10 произнесений каждого слова. Каждый школьник добавляет один пример — никакого программирования.

Как записывать: нажми «Начать запись», произнеси только указанное слово, нажми «Сохранить WAV». Длительность — 0,4–5 секунд. Имена файлов назначаются автоматически: 01.wav, 02.wav… отдельно для каждой команды.
