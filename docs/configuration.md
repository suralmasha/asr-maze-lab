# Настройка лаборатории

Общие параметры сервера и интерфейса находятся в [config/lab.json](../config/lab.json). Меняйте этот файл для ограничения ресурсов, изменения шкал элементов управления и начальных параметров эксперимента. JSON не поддерживает комментарии.

| Раздел или ключ                                                 | Назначение и значения в поставке                                                                                                                                                                                                                                                   |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cache_max_bytes`                                               | Лимит дискового LRU-кеша: 400 000 000 байт. История моделей и исходные WAV хранятся отдельно                                                                                                                                                                                       |
| `audio.min_samples`, `audio.max_samples`                        | Минимум и максимум записей на команду: 5 и 50                                                                                                                                                                                                                                      |
| `audio.min_seconds`, `audio.max_seconds`                        | Длительность записи в интерфейсе: от 0,4 до 5 секунд                                                                                                                                                                                                                               |
| `audio.validation_max_seconds`                                  | Верхняя граница WAV при проверке сервером: 5,5 секунды, с запасом к времени остановки записи                                                                                                                                                                                       |
| `audio.max_bytes`                                               | Максимальный размер загружаемого аудио: 200 000 байт                                                                                                                                                                                                                               |
| `feature_scales`                                                | Значения бегунков для `n_mels`, `n_mfcc`, `n_fft` и `hop_length`; исходные шкалы приведены в `config/lab.json`                                                                                                                                                                     |
| `limits`                                                        | Допустимые границы `n_mels` (8-128), `n_mfcc` (2-40), `k` (1-15), `noise` (0-0,1) и `denoise_strength` (0-2)                                                                                                                                                                       |
| `preprocessing.strength_step`, `preprocessing.preview_strength` | Шаг силы шумоподавления (0,1) и сила предварительного просмотра (1)                                                                                                                                                                                                                |
| `noise_levels`                                                  | Уровни добавляемого шума в интерфейсе: 0, 0,03 и 0,08                                                                                                                                                                                                                              |
| `defaults`                                                      | Начальные признаки, обработка и классификатор: 32 мел-фильтра, 13 MFCC, окно 512, шаг `null`, сила шумоподавления 0, окно шумоподавления 512, нормализация включена, евклидово расстояние, голосование по расстоянию, 3 соседа, обрезка тишины включена, добавление шума выключено |

`defaults.hop_length: null` выбирает четверть размера окна. Начальное число обучающих записей на команду берется из `audio.max_samples`.

## Применение изменений

1. Остановите сервер через `Ctrl+C` в терминале запуска или `make down`.
2. Измените `config/lab.json`, сохранив структуру JSON и согласованные значения.
3. Запустите `make server` либо `make server-cache` и перезагрузите открытые страницы. Браузер получает тот же конфиг через локальный `/lab-config.js`; вручную редактировать этот ответ не требуется.
4. Проверьте шкалы и текущие значения в интерфейсе. Сохраненные параметры из `models/lab_settings.json` имеют приоритет над `defaults`. Если нужно изменить уже примененные признаки или обработку, выберите значения в интерфейсе и нажмите «Применить», затем обучите модель заново.

Для обновления настроек не требуется `make clean`: эта команда удаляет записи, модели и другие результаты работы.

Некорректный JSON или несогласованные параметры останавливают запуск с ошибкой `ASR-CFG-02`. Исправьте конфиг и повторите запуск; скрытые резервные значения не подставляются. Фоновый предрасчет использует варианты из `feature_scales`, поэтому расширение шкал увеличивает объем работы и кеша.

## Согласованность параметров

- Лимит кеша, число записей и лимит байтов - положительные целые числа; минимум не превышает максимум. Длительности удовлетворяют `0 < min_seconds <= max_seconds <= validation_max_seconds`. Для PCM с заголовком требуется `max_bytes >= ceil(validation_max_seconds * 16000 * 2) + 44`.
- Шкалы `feature_scales` непустые, строго возрастают и содержат положительные целые числа. Мел-фильтры и MFCC укладываются в `limits`; окна FFT - степени двух не меньше 4. Начальные значения должны присутствовать в соответствующих шкалах, включая вычисленный шаг при `hop_length: null` и окно шумоподавления.
- Число MFCC не превышает число мел-фильтров, шаг не превышает окно. Это относится и к начальным значениям; минимум шкалы MFCC не превышает минимум шкалы мел-фильтров, а минимум и максимум шкалы шага не превышают соответствующие границы шкалы FFT.
- `noise_levels` строго возрастают, укладываются в `limits.noise` и содержат начальный уровень. Нижние границы шума и силы шумоподавления равны нулю. Сила предварительного просмотра укладывается в диапазон; положительный шаг силы делит его без остатка.
- `metric` принимает `euclidean` или `manhattan`, `weights` - `uniform` или `distance`. Число соседей ограничено также количеством обучающих примеров.

После изменения границ ранее сохраненные настройки или модель могут оказаться недопустимыми. В этом случае выберите совместимые параметры и переобучите модель. Одно изменение `defaults` не преобразует уже обученный классификатор.

## Фиксированные свойства

Частота WAV 16 кГц, один канал и PCM 16-bit остаются частью протокола. Конфиг не меняет четыре класса команд и HTTP-маршруты приложения.

У старых моделей версии 1 сохранено исходное представление признаков. Новые модели версии 2 используют параметры своего обучения; изменение `defaults` не меняет признаки существующей модели. Сужение допустимых границ может помешать загрузке прежней модели версии 2, если ее параметры выходят за новые пределы.
