# «Научи робота слышать» - офлайн-мастер-класс

Участники записывают 4 голосовые команды, изучают звуковые признаки, обучают классификатор и управляют роботом в лабиринте. Система не нуждается во внешнем распознавании речи или подключении к API.

Мастер-класс можно провести без интернета, если окружение с зависимостями подготовлено заранее.

## Быстрый старт

Требуются Python 3.10+, `make`, микрофон и браузер с поддержкой записи звука.

1. В папке проекта подготовить окружение:

   ```bash
   make setup
   ```

   Команда создает `.venv` и устанавливает зависимости из `requirements.txt`.

2. Запустить локальный сервер:

   ```bash
   make server
   ```

3. Открыть [сбор записей](http://localhost:8000/collect.html) и разрешить браузеру доступ к микрофону.
4. Пройти этапы с помощью кнопок внизу страниц или верхней навигации.

Сервер работает на `127.0.0.1:8000`. Аудиозаписи и обученная модель сохраняются на компьютере, где запущен проект.

## Режимы вычислений

По умолчанию `make server` запускает режим `on-demand`: графики и признаки рассчитываются при запросе, сохраняется только последняя обученная модель. Явный запуск: `make server MODE=on-demand`.

Для фоновой подготовки и истории моделей запустить `make server MODE=precompute`. На этапах «Шумоподавление» и «Признаки» сначала готовятся варианты выбранной записи, затем остальных. Запрошенный пользователем вариант получает приоритет; если он еще не готов, интерфейс показывает ожидание. «Звук» и «Сравнение» рассчитываются при просмотре в обоих режимах.

Готовые PNG, обработанное аудио и числовые признаки сохраняются в дисковом LRU-кеше до **400 МБ** (400 000 000 байт). При заполнении фон останавливается, новые запросы вытесняют наиболее давно использованные результаты. После перезапуска кеш доступен сразу; фон запускается при входе на соответствующий этап. Кнопка **«Очистить кеш»** останавливает очередь и удаляет результаты; фон возобновится при следующем входе в «Шумоподавление» или «Признаки». Исходные WAV и модели эта кнопка не удаляет.

В режиме `precompute` на обучении доступна история моделей. Повторное обучение с тем же датасетом и настройками сразу активирует сохраненный вариант. Выбор модели восстанавливает ее настройки на всех этапах. Можно удалить выбранную модель или все модели; история хранится отдельно от лимита кеша. Изменение имен или содержимого исходных WAV сбрасывает кеш и прежнюю историю, включая активную модель этого режима.

Примененные параметры общие для локального сервера и сохраняются на диске. Один сервер предназначен для одного участника.

## Этапы

### 1. Данные

Для каждой команды - **вверх**, **вниз**, **влево**, **вправо** - требуется от **5 до 50 записей**. Кнопка **«Начать запись»** включает микрофон, **«Остановить и сохранить»** сохраняет произнесенное слово. Записи доступны для прослушивания и удаления.

Сервер создает WAV в формате 16 кГц, mono, 16-bit PCM. Имена назначаются автоматически: `dataset/up/01.wav`, `dataset/down/01.wav` и аналогично для остальных команд. После сбора данных кнопка **«К звуку»** открывает следующий этап.

### 2. Звук

Для 1 записи показываются волновая форма, усредненный спектр и спектрограмма с пояснениями. Параметры анализа фиксированы. Кнопка **«К сравнению»** открывает следующий этап.

### 3. Сравнение

Для 2 выбранных аудиозаписей показываются волновая форма, усредненный спектр и спектрограмма с одинаковыми шкалами. Блоки выбора находятся слева, соответствующие ряды графиков - справа. Этап предназначен для сравнения разных слов и разных голосов; настройки анализа фиксированы.

Кнопка **«К шумоподавлению»** открывает следующий этап.

### 4. Шумоподавление

Волновая форма и спектрограмма исходной записи сравниваются с результатом мягкого спектрального шумоподавления. Шум оценивается по 20% самых тихих окон. Сила обработки и размер окна регулируются.

На этом этапе также выбирается удаление тишины по краям. Кнопка **«Применить»** сохраняет обработку для всех данных на следующих этапах. Один и тот же фильтр и обрезка используются при построении признаков, обучении и распознавании; исходные WAV сохраняются. Кнопка **«К признакам»** открывает следующий этап.

### 5. Признаки

Для выбранной записи доступны волновая форма, спектрограмма, банк треугольных мел-фильтров и мел-спектрограмма. Бегунки изменяют параметры:

| Параметр | Значения |
|---|---|
| Мел-фильтры (`n_mels`) | 8, 16, 32, 64, 128 |
| Коэффициенты MFCC (`n_mfcc`) | 4, 8, 13, 20, 32; не больше числа мел-фильтров |
| Размер окна (`n_fft`) | 256, 512, 1024, 2048 отсчетов |
| Шаг окна (`hop_length`) | 64, 128, 256, 512 отсчетов; не больше размера окна |

Изменения видны на графиках после расчета. Кнопка **«Применить»** сохраняет выбранные признаки для всех обучающих записей. Кнопка **«К обучению»** открывает следующий этап. Настройки сохраняются на сервере, а при обучении - вместе с моделью.

### 6. Обучение

Кнопка **«Обучить модель»** запускает извлечение признаков и обучение k-NN. По умолчанию используются все сохраненные записи, до **50 на каждую команду**. Число ближайших соседей меняется от **1 до 15** и не превышает число обучающих примеров.

Доступны настройки для экспериментов:

| Настройка | Что можно исследовать |
|---|---|
| Нормализация признаков | Как масштаб признаков влияет на поиск соседей |
| Метрика расстояния | Чем отличаются евклидово и манхэттенское расстояния |
| Взвешивание соседей | Как меняется результат при равном голосовании и большем весе ближайших записей |
| Число обучающих записей | Как объем датасета влияет на результат |
| Добавление шума | Как шумные обучающие примеры влияют на устойчивость модели |

Для добавления шума доступны 3 варианта: без шума, слабый (3%) и сильный (8%). При добавлении шума для каждого обучающего аудио создается 1 дополнительный пример после шумоподавления. Изменение параметров применяется при следующем обучении. Исходные WAV сохраняются.

На графике **«Как модель видит записи?»** каждая точка соответствует обучающему примеру. Выбор точки показывает имя WAV-файла. Это проекция PCA в 2 координатах; классификатор вычисляет расстояния по всем выбранным признакам.

Кнопка **«Произнести команду»** записывает новый пример для проверки модели. Результат показывает распознанную команду и ближайшие обучающие записи с расстояниями. Модель сохраняется в `models/keyword_classifier.npz`; кнопка **«К лабиринту»** открывает игру.

При проверке и в лабиринте переключатель **«Шумоподавление»** позволяет отключить фильтр для новой голосовой команды. По умолчанию фильтр включен с параметрами активной модели; переключатель не меняет модель и настройку обрезки тишины.

### 7. Лабиринт

4 правила связывают слова с направлениями движения. Кнопка микрофона записывает команду, обученный классификатор определяет ее класс, и робот делает шаг по лабиринту.

Текстовый ввод позволяет проверить правила движения отдельно от распознавания голоса.

## Как устроено распознавание

Это учебный классификатор 4 коротких команд (keyword spotting). Обучающая цепочка: PCM WAV -> обработка сигнала -> STFT -> мел-фильтры -> MFCC -> нормализация при включенной настройке -> k ближайших соседей. Обучающие примеры и метки задаются записями участников.

k-NN сопоставляет новую запись с сохраненными примерами. Модель всегда выбирает 1 из 4 классов, в том числе для посторонних слов. Результат зависит от количества записей, голосов, громкости, темпа речи и выбранных настроек. Близость точек на проекции PCA не равна расстоянию, по которому принимается решение.
