# История изменений

## 1.0.0 - 2026-10-22

Первый релиз учебной ASR-лаборатории для офлайн-мастер-класса.

### Добавлено

- 7 этапов: данные, звук, сравнение, шумоподавление, параметры, обучение и лабиринт.
- Запись четырех голосовых команд, прослушивание WAV и выгрузка датасета в ZIP.
- Волновая форма, спектр, спектрограмма и сравнение записей.
- Демонстрация дискретизации от 1 до 16 кГц без изменения исходного аудио.
- Шумоподавление, удаление пауз по краям и интерактивные параметры MFCC и мел-фильтров.
- Обучение k-NN, проекция записей в PCA и распознавание новых команд.
- Управление лабиринтом голосом и текстом.
- Режимы вычислений по запросу и с предрасчетом, дисковый кеш и история моделей.
- Общая конфигурация лаборатории, локальные ресурсы интерфейса и документация запуска.
- Автоматические тесты, линтеры, pre-commit и GitHub Actions для Python 3.10 и 3.12.

### Исправлено

- Совместимость pre-commit с Python 3.10.
- Порядок удаления записей из дискового кеша при быстрых обращениях и после перезапуска.
