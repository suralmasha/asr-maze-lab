# Быстрый старт

В папке проекта:

1. Подготовить окружение:

   ```bash
   make setup
   ```

2. Запустить сервер:

   ```bash
   make server
   ```

   Для фонового предрасчета, кеша до 400 МБ и истории моделей: `make server MODE=precompute`. Обычный запуск рассчитывает результаты по запросу и хранит только последнюю модель.

3. Открыть [сбор записей](http://localhost:8000/collect.html) и разрешить доступ к микрофону.
4. Собрать от **5 до 50 WAV** для каждой из 4 команд.
5. С помощью кнопок пройти этапы: **Звук -> Сравнение -> Шумоподавление -> Признаки -> Обучение -> Лабиринт**. На этапах шумоподавления (включая обрезку тишины) и признаков настройки сохраняются на сервере кнопкой **«Применить»**.

На этапе обучения кнопка **«Обучить модель»** использует все записи по умолчанию. Параметры позволяют менять представление звука и поиск ближайших соседей, а новый голосовой пример - проверить результат. Сохраненная модель автоматически используется в лабиринте.

Требования, описание этапов и ограничения приведены в [README.md](README.md).
